# ינשוף · קורא PDF מתרגם

פותחים PDF, מקישים על משפט — והתרגום קופץ. עובד גם בלי אינטרנט.

- הקשה על משפט = סימון + תרגום, חצים למשפט הבא/הקודם
- סימון חופשי + "תרגם סימון", ותרגום עמוד שלם
- אופליין: מודל NLLB‑200 שרץ בדפדפן (הורדה חד־פעמית), או המתרגם המובנה של כרום במחשב; כל תרגום נשמר במכשיר
- ספרייה מקומית, מחברת משפטים, מצב לילה, התקנה כאפליקציה, "פתח באמצעות" / שיתוף PDF לאפליקציה

Built with pdf.js and Transformers.js (vendored in this repo).
